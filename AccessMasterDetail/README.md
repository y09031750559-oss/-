# Главная и подчинённая форма + база Access (C#, Visual Studio)

Открыть `AccessMasterDetail.sln` → нажать **F5**.

- `Shop.mdb` — база Access: таблицы `Clients` (главная) и `Orders` (подчинённая, связь по `ClientID`).
- `MainForm.cs` — главная форма: клиенты + заказы выбранного клиента.
- `OrdersForm.cs` — подчинённая форма (двойной щелчок по клиенту): заказы текущего клиента.
- `Db.cs` — подключение к Access через OleDb, загрузка и сохранение.
- `Grids.cs` — настройка таблиц.
- `Filters.cs` — фильтры: таблицы меняются сразу при вводе (клиенты — по ФИО/телефону и городу, заказы — по товару и цене от).

Формы связаны через `DataRelation` + `BindingSource`: выбираешь клиента в главной — подчинённая показывает его заказы.
Драйвер — встроенный в Windows Jet 4.0 (поэтому проект x86), устанавливать ничего не нужно.
